## Know the codebase — the module map

**`MODULE-INDEX.md`** (auto-generated by `tools/gen-module-index.mjs`) is a one-page map of **every** module:
its file, schema/table counts, tables, and public `C_`/`A_`/`X*` entrypoints + a one-line purpose. Read it
for **instant recall of the whole codebase shape**, then open the one module you need. Re-run the generator
after modules change. This is your "know the code" layer — you don't hold every module in your head, you
look it up here in one glance, then scan the specific file.

## Before writing code in a module — SCAN IT

Find the module in `MODULE-INDEX.md`, then read its `.pact` (its interface + its `.repl` tests too) to learn its real schemas, tables, prefixes, caps, and neighbours. "Make an info function for module X" means: look at how sibling modules expose their `UR_*` / `INFO-*` readers and mirror that shape for X's schema — don't invent, imitate. When unsure of a pattern, **grep the codebase** for it rather than guessing. Knowing the code beats remembering it.

## Non-negotiables (fast recall — full rules in StoicSyntax.md)

- **Prefix is the contract.** Validation lives ONLY in the master `defcap` / `UEV_`; `C_`/`XI_`/`XE_`/`W_` carry no `enforce`. `C_` body only wires: `UEV_IMC → with-capability → XI_`.
- **No `use`, no `MODULE.fun`** — cross-module = `(ref-X:module{Iface} X)` + `::`; resolves at load (target must pre-exist).
- **No foreign caps** (compose/with/require only home caps); `(UEV_IMC)` is the FIRST statement of a cross-module mutator, never `enforce`-wrapped.
- **`and` is binary** → `(fold (and) true […])` for 3+. **No `URD_`/`URDC_`/`(keys …)`/`select` on the execution path** (aggregate table + `UR_` point read instead).
- **Body order:** enforce → bare ref → home → caps (`compose-capability` last). `W_` = one persistence op, last, nothing after. **No `@managed` in-house** — composed bands + `SECURE`.
- **Deploy:** Utilities → Core → Talos; a new `C_`/`A_`/`X` isn't production-final until wired into Talos. Interfaces are versioned (+1); cascade every `implements`/`module{…}`/`object{Iface.Schema}` ref.
- **Tests:** namespace `ouronet-ns`; integration in `REPL/Stage_*`, scratch in `REPL/Kursan/`; run `pact <file>.repl`.

## Active learning — when the owner corrects you

If the owner says "do X instead of Y," **that is a rule, not a one-off.** Capture it in the SAME turn:
1. Append a dated note to `memories/YYYY-MM-DD-<topic>.md` (what was wrong → what's right → why).
2. If it's a durable rule, fold it into the matching `pact/*` or `ouronet/conventions/*` doc — and into `StoicSyntax.md` if it changes the discipline itself.
These docs are the source of truth; keeping them current is what lets the next agent get it right **without being told twice.**
