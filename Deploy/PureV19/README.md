## A bug this round found in the generator

`round_modules()` built its cascade pattern with `"|".join(rnd["interfaces"])`. For a round that
bumps **no** interface that is `re.compile("")` — which matches **every file**. V19 is the first
such round, and its first generation emitted **25 transactions**, the whole from-scratch pipeline,
instead of the one its `also` names.

The failure is quiet and in the dangerous direction: a round that ships far more than intended
looks like a thorough round, and the extra modules are all byte-identical redeploys that would
have succeeded. Guarded — an empty cascade now returns the empty set, and such a round leans
entirely on `also`, which is applied by the caller.
