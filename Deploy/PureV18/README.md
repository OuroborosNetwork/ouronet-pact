## Why 18 is next

V17 **shipped** — the owner confirmed it on 2026-10-30, along with the fact that its post-deploy
scripts were never run. So `1_SOVEREIGN/` was at parity again, and the vacate work is a fresh
divergence: a new round rather than an amendment to the old one. `Deploy/PureV17/` is the record
of what went out and must not be regenerated — `_deploybundle.py --write` rewrote it once during
this round's construction (replacing `V6` with `V7` in a shipped artefact) and it was reverted.

## The round's own selector

This round introduced an `also` key to `ROUNDS`. `round_modules` selects by interface cascade,
which is blind to a module whose BODY changed while its signatures did not — AQP-VCT exactly.
`extra` was the wrong tool (it exists for modules in no deploy chain and labels them so, while
AQP-VCT is in batch 20), and listing an unbumped interface under `interfaces` would have made the
round metadata assert a bump that never happened. `also` is a third thing and says so.

Without it the round would have shipped a Talos whose wrappers call the OLD vacate — the pool
would still have re-opened itself, and every test would still have passed, because the tests run
against the repo and not against what the round carries.
