# REPL analysis tooling — INDEX

Generated by `python3 tools/_toolindex.py` from each script's first docstring line. Regenerate after
adding a tool.

**Read this before writing a new analysis script.** There are 61 here, and duplicates have been
built more than once — an eager-let detector, a write-leak auditor and a Pact comment stripper have
each been re-derived by someone who did not know the original existed. The stripper in particular
is why `_pactlex.py` exists: import from it rather than re-writing `strip_comments`, which has
shipped broken (Pact `@doc` strings continue across lines with a trailing `\`, and a naive escape
parser desyncs on them) at least four times.
