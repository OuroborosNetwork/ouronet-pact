# REPL/archive/ — kept for history, never run

Files here contain **no assertions** and are **referenced by nothing**. They are gas probes,
scratch drivers and superseded harnesses — evidence of past investigation, not tests.

Archived by P1 (2026-09-09). Nothing was deleted: git has the full history, and a probe that
turns out to matter can be lifted back out and given assertions.

**Do not add to this directory.** A file with assertions belongs in a tester; a file without them
is either a fixture (`REPL/fixtures/`) or it does not belong in the suite.
