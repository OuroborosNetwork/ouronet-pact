# ouronet-pact — the single entry point

**Before writing or reviewing any Pact in this repo, load the hub:**

- [`OuronetInformational/SKILL.md`](../../../OuronetInformational/SKILL.md) — the ONE file. It gives the
  load order, the fast-recall rules, the **scan-the-module-first** habit (via
  [`OuronetInformational/MODULE-INDEX.md`](../../../OuronetInformational/MODULE-INDEX.md) — a one-page map of
  every module's schemas/tables/public `C_`/`A_`/`X` entrypoints), the Pact 5 language layer
  ([`pact5/`](../../../OuronetInformational/pact5/)), and the active-learning protocol.

It links everything else — `StoicSyntax.md`, `ouronet/conventions/*`, `pact5/`, `MODULE-INDEX.md`. The
other `ouronet-*` skills (`ouronet-ur-layout`, `ouronet-w-writes`, `ouronet-x-function-guards`, …) are the
detailed sub-topics; **this** is the map that ties them together. Load this first, then the specific one.
