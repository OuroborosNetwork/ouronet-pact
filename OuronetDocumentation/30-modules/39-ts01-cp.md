# TS01-CP — Stage-1 multi-step client orchestration

## What it is for

The client surface for the multi-step pool operations — issuance and liquidity addition as ordered continuations.

Talos is **the only supported client path**. Core modules build an unfinished bill that only Talos may settle, and the gas station sponsors **only** shapes it recognises. A core client function called directly would not have its gas paid and could not collect.

## Where it sits

Beside the main Stage-1 swap orchestrator, for the operations that cannot complete in one transaction.

## Traps

**These are the ten entrypoints that are only partly sponsored.** The first step carries transaction code the gas station can inspect; every continuation does not, so **the customer pays for the rest**. An interface telling users transactions are free will be wrong here.

**Nothing can expire an abandoned continuation.** Pact has no scheduled execution.
